# Obsidian × Claude Code で作る「第二の脳」

動画の要点: Obsidian の vault（実体はただのフォルダ＋素の Markdown）を Claude Code に渡し、
「読んで育てる説明書」（`CLAUDE.md`）を1つ置くだけで、資料を投げ込むたびに AI が要約・
関連づけ・目次づくりまでやってくれる「使うほど賢くなる外付けの脳」が作れる。

## このサンプルが示すこと

- `raw/` … 人間が置く生の資料（**不変**。AI は読むだけ）
- `wiki/` … AI が書き、育てるページ（要約・概念・人物/組織）
- `CLAUDE.md` … 全ルールが書かれた説明書。動画でいう「テンプレートはこれ」の実体

このフォルダをコピーして `raw/` に自分の資料を置けば、動画と同じ仕組みがそのまま動き
始めます。

## 前提

- **Obsidian・git・Claude Code** がインストール済みで、**Claude Code にログイン済み**であること
- ターミナル（Mac は「ターミナル.app」、Windows は PowerShell 等）が使えること
- 追加の API キーや有料サービスは不要です

## セットアップ

1. このフォルダ（`second-brain-vault/`）を丸ごとダウンロードして好きな場所に置く
   （例: `~/second-brain-vault`）

   > このリポジトリごと `git clone` した人へ: そのまま次の `git init` をすると
   > リポジトリの中にリポジトリができてしまいます。**必ずこのフォルダだけを
   > リポジトリの外にコピーしてから**、次に進んでください。
2. ターミナルでこのフォルダに移動し、**git 管理を開始して最初のコミットまで作る**
   （`git init` だけだと後で「変な変更を戻す」ができないので、必ずコミットまで行う）:

```bash
git init
git add .
git commit -m "Initial vault backup"
```

3. Obsidian を開き、「Open folder as vault」でこのフォルダを vault として開く
4. ターミナルで同じフォルダに入り、Claude Code を起動する:

```bash
cd <このフォルダ>
claude
```

vault の実際のパスが分からないときは、Obsidian の「設定 → Vault の情報」
（または vault 切り替え画面で対象 vault にカーソルを合わせる）で確認できます。

## 3つの操作をそのまま頼む

`CLAUDE.md` に書かれた3つの操作（取り込み・質問・健康診断）を、そのままコピペして
Claude Code に投げられます。

### 1. 取り込み（Ingest）

```
raw/2026-01-01_sample-article.md を取り込んで。
既存ページと重複していないか確認し、出典を残して wiki を更新し、
変更内容を wiki/log.md に記録して。
```

### 2. 質問（Query）

```
TaskLoom の重複検知はどういう仕組み？wiki を見て、出典つきで教えて。
```

（`raw/2026-01-01_sample-article.md` は取り込み実験用のダミー記事です。事前に1で
取り込んでから聞くと出典つきで答えが返ってきます）

### 3. 健康診断（Lint）

```
wiki の健康診断をして。範囲は前回の健康診断以降に変わったファイルだけでいい。
矛盾や孤立ページがあれば wiki/lint-report.md にまとめて。
```

## 期待出力

取り込み（1）を1回頼むと:

- `wiki/summaries/` に要約ページが1つできる
- 記事の中身によっては `wiki/concepts/`（例: 重複検知の仕組み）や
  `wiki/entities/`（例: 人物・組織）にもページができる
- `wiki/index.md` に新しいページへのリンクが追加される
- `wiki/log.md` に「いつ・何を取り込んだか」の記録が追記される

**何も起きなかったとき**は次を確認してください:

- `claude` をこのフォルダの直下（`CLAUDE.md` があるフォルダ）で起動しているか
- 指定した raw ファイルのパスが合っているか（`raw/2026-01-01_sample-article.md`）
- ターミナルに「実行していいですか？」という確認が出て止まっていないか（許可すると進みます）

## 変更の確認と戻し方

AI に何かを頼んだら、コミットする前に必ず中身を確認してください:

```bash
git status   # 何が変わった/増えたか一覧
git diff     # 中身の差分
```

問題なければコミットします。おかしな変更が入っていたら、コミットする前に

```bash
git restore <ファイル名>
```

で元に戻せます（すでにコミットしてしまった場合は、直前のコミットに戻す
`git reset --hard HEAD~1` などがありますが、これは元に戻せない操作なので、
心配なときは実行前に一度立ち止まってください）。

## 注意

- git はこの PC の中の変更履歴であって、**PC 故障・紛失に耐えるバックアップではありません**。
  大事な vault は別途クラウド同期やリモートリポジトリへの push も検討してください。
- ここに登場する記事・企業名・人物名（Acme Software、TaskLoom、Jane Doe など）は
  すべて動作確認用の架空のものです。
