# Claude Code の mods のしくみ（見本：入力欄の上に「いま何をしているか」を出す mod）

動画の要点：mods は、Claude Code の見た目と動きを変える仕組み。中で起きるイベントにフックを登録して、観察・書き換え・応答と、描画ができる。
フックは、mod が登録するイベントハンドラ（イベントが起きたときに Claude Code が呼ぶ、自分の小さな関数）。
イベントのおもなものは、プロンプトの送信・ツール呼び出し・ターンの終了・描画。そして、その mod は**頼めば Claude Code が書いてくれる**。

このサンプルは、その仕組みを目で見るための実物（できることの例の1つ）。入力欄の上にバンド（枠）を描画し、
「何のための作業か／さっき頼んだこと／いまやっていること／AIの記憶をどれだけ使ったか」を常に見せる。

## この見本が示すもの

どのイベントにフックを登録して、何を観察して、何を描画しているか。この mod は6つのイベントにフックを登録している（`now-doing/hooks/now-doing.mjs`）:

| イベント | 該当する行 | 動き | やっていること |
|---|---|---|---|
| 会話が始まったとき（`session.start`） | L23-27 | 観察 | 会話の使用割合を `$.session.usage()` で読み、「記憶」の行の最初の値にする |
| プロンプトが送信されるとき（`prompt.submit`） | L29-45 | 観察 | 頼んだ一言を覚える。最初の発言は仮の目的にする。**そのあと小さいAIで、目的の更新と一言の言い直しをする（AIを呼ぶのはここだけ）** |
| ターンが始まったとき（`turn.start`） | L47-53 | 観察 | 「いま」の行を作業中にする（すでに「いま」の行があるときだけ） |
| ツールが実行される直前（`tool.call`） | L55-62 | 観察 | ツール名と対象（ファイル名など）を「いま」の行に書き、手数を1つ増やす |
| ターンが終了したとき（`turn.complete`） | L64-72 | 観察 | 「いま」の行を待機中にし、会話の使用割合を読み直す（公式の説明では、この読み取りは無料） |
| 描画箇所が描画される直前（`ui.render` の入力欄の上＝バンド。AbovePrompt） | L74-85・L120-144 | 描画 | 入力欄の上にバンドを描画する。Claude Code 自身はここに何も描画しない |

`turn.start`・`tool.call`・`turn.complete` は、サブエージェントではなく本体の会話のイベントだけを扱う（手数にもサブエージェントの分は入らない）。

描画のフック以外は `next(e)` をそのまま返す。描画のフックも、描画しない場面（アンケート表示中、またはまだ最初の発言が無いとき）は `next(e)` を返し、描画するときだけ自分のバンドを返す（L80-85）。つまり**イベントは変えず、観察（5つ）と描画（1つ）だけ**で、
書き換え・応答は使っていない。（前からある設定ファイルの hooks は、公式は Settings hook と呼ぶ別の仕組み。この見本は mod のフックだけを使っている）

## 動かし方

必要なもの: Claude Code **2.1.287 以降**（mods は最初から有効で、スイッチは要らない）。

```
claude --version
git clone https://github.com/todoroki-godai/zundamon-explainer-samples.git
claude plugin validate ./zundamon-explainer-samples/claude-code-mods/now-doing
claude plugin test ./zundamon-explainer-samples/claude-code-mods/now-doing
claude --plugin-dir ./zundamon-explainer-samples/claude-code-mods/now-doing
```

1. `claude --version` が `2.1.287` 以上であること。古ければ更新する
2. 取得する。mod のフォルダは `claude-code-mods/now-doing/`
3. `validate`（入れる前の検査）。この mod が「どのイベントを扱い、何を呼ぶか」の一覧が出て、最後に `✔ Validation passed`
4. `test`（付属の試験）。`3 pass` / `0 fail`。試験の中ではAIの呼び出しを差し替えてあるので、AIは使わない
5. `--plugin-dir` で起動すると、このフォルダの mod がこの起動のあいだだけ読み込まれる
6. 入力欄に何か頼む。**起動直後は何も出ず、最初の発言を送ると枠が出る**

読み込めたかは、公式の説明では `/plugin` の見出しの下に、動作中の mod の数と名前が薄い字で出る。
公式ドキュメント（作り方）によると、Claude Code は `--plugin-dir` で読み込んだフォルダを監視していて、中のファイルが変わるとフックを定義したモジュールを自動で読み込み直す。mod を書き換えたら、その場で反映される。

## 動かすと何が見えるか

入力欄のすぐ上に、丸い角のバンド（枠）が描画される。中は最大4行:

| 行 | 何が出るか |
|---|---|
| 目的 | 会話全体の目的。最初は最初の発言がそのまま入り、AIの言い直しが返ると、AIが短くまとめ直した文に置き換わる。30字以内と頼んでいるが、守られず長くなり、行末が `…` で切れることがある |
| 直近 | さっき頼んだ一言の言い直し。言い直しが失敗したとき・まだ返らないときは、打った原文のまま |
| いま | 作業中は「ツール名: 対象（N手目）」（例: ファイルを読むとファイル名が出る）。返事が終わると「待機中（N手で完了）」 |
| 記憶 | `記憶 30%` のように、会話の使用量が窓のどれだけかの割合。あわせて `要約に使った分 入力 … / 出力 … トークン（N回）` が出る。これは言い直しのためにAIを呼んだ累計 |

行の色は、目的がマゼンタ、直近がシアン、いまは作業中が黄・待機中が緑。

## 使うトークン

- **表示そのものはAIを呼ばない**（「いま」「記憶」「枠」）。AIを呼ぶのは、頼んだ一言の言い直し1か所だけで、発言1件につき1回
- 使うモデルは別名 `haiku`。返す量の上限は120トークン（`now-doing.mjs` L101）
- 実測: **1回あたり平均およそ300トークン**（入力約218＋出力約80）。条件: 2026-10-02、Claude Code 2.1.287、1つの会話で、目的の行を足したあとの5回の合計（入力1,091＋出力401）÷5。画面の累計表示（8回で入力1,292／出力490）から、目的の行を足す前の3回（入力201／出力89）を引いて出した。**1つの環境の実測で、利用枠や料金にどれだけ効くかは測っていない**
- 言い直しを止めるには、`hooks/now-doing.mjs` の4行目 `const SUMMARIZE = true;` を `false` にする。AIは呼ばれなくなり、目的と直近の行は打った原文のまま出る

## Claude Code にどう頼むか

中身を読んで理解する:

```
claude-code-mods/now-doing/hooks/now-doing.mjs を読んで、どのイベントにフックを登録して、何を観察して、何を描画しているか説明して。
AIを呼んでいる箇所と、ファイル・通信・プロセスに触れている箇所があるかも教えて。
```

自分用に作り替える:

```
この mod を作り替えて。「目的」の行は要らない。言い直しのAIも使わず、打った原文をそのまま出して。
```

最初から作らせる（公式ドキュメントの例）:

```
入力欄の上に、いま使っているブランチ名を出す mod を作って
```

プログラムの書き方を知らなくてよい（公式ブログにも、頼み文は「何が見えてほしいか」だけでよいと書かれている）。
Claude Code が書いた mod は、**その会話のあいだだけ**読み込まれ、あとで片付けられる。
残したいときは、フォルダを別の場所へコピーして `claude --plugin-dir` で読み込む（公式ドキュメントの手順）。

## 注意

- **人が配っている mod は、入れた人（あなた）のパソコンの中で、入れた人（あなた）と同じ権限で動く。** ファイルを読み、命令を出し、環境変数や設定（APIキーを含む）にも届き、サンドボックスの外にある。公式も「信頼できる人のものだけ入れる」と書いている。**入れる前に中身（`hooks/now-doing.mjs`）を読むこと。** `claude plugin validate` の `hooks:` と `calls:` の行で、扱うイベントと呼ぶものが一覧できる。この mod の `calls:` は `$.model.complete`（AIを呼ぶ）、`$.session.usage`、`$.state.get`/`$.state.set`、`$.ui.resolve` で、ファイル・プロセス・通信の呼び出しは含まれない
- **この mod は、頼んだ一言を短く言い直すためにAIを呼ぶ。** その分は自分のプラン（またはAPIキー）の利用分を使う。実測値は上の「使うトークン」。止め方も同じ節
- **小さいAIの言い直しは、取り違えることがある。** 制作中の実測でも、発言の一部が落ち、別の言葉（「前置き」）に置き換わった例があった。発言の一部が落ちる、別の言葉に置き換わる、30字を超える、が起こりうる。大事な判断にはバンドの表示でなく、打った原文と会話を見ること
- 止めたいとき: `/plugin` の Installed タブで、その mod を無効にする。1回だけ全部止めるなら `claude --safe-mode`（公式ドキュメント）
- 数値はすべて**特定の1つの環境での実測**。確認したのは CLI のみで、Desktop の Code タブや VS Code 拡張での動きは未確認
