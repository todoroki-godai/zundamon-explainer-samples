# evidence — 「止まった」と「代わりに読んだ」を1回ずつ記録したもの

動画の④で使った実測の生ログです。5,507行の実ファイル1本に対して、同じ道具を2回動かしました。

## hook_demo.jsonl — 見張りが止めたときの記録

| 行 | 意味 |
|---|---|
| `{"event": "called", "tool": "Read"}` | 見張りが呼ばれた |
| `{"event": "blocked", "path": "...make_figures.py", "lines": 5507}` | 5,507行なので止めた |
| `{"event": "called", "tool": "Bash"}` | 直後にAIが別の読み方（Bash）へ回り込んだ |

3行目が動画で言っている「塞ぎ残しが1つあれば抜けられる」の実物です。

## worker_demo.jsonl — 代わりに安いAIへ読ませたときの記録

```json
{"worker_file": "...make_figures.py", "worker_sec": 47, "worker_in": 166109, "worker_out": 3600, "worker_cost": 0.32399659999999997}
```

- `worker_sec: 47` — 5,507行を47秒で要約した（本編は「1分もかからず」と丸めています。**別の回で35秒だったのでばらつきます**）
- `worker_in` / `worker_out` — そのとき読み書きしたトークン数
- `worker_cost` — **定価に換算した金額**。定額プランを使っている場合、この額が追加請求されるわけではありません

## 注記

- `path` / `worker_file` は個人のディレクトリを除いてあります（`probe_demo/` から下だけ）
- 対象ファイルはこのチャンネルの動画ビルド用スクリプトの実物で、リポジトリには含めていません。
  自分で試すときは、手元にある**1,000行を超えるファイル**を1本使ってください
